# 2026-08-03

## 修复：边栏不可见 + 切回主页自动播放暂停

用户报告两个 bug：
1. 左右页面的边栏（信息页/设置页）没有出现（黑屏）
2. 切换到中间播放页必须自动播放，不能中途暂停

### 根因（TDD 验证）

**BUG-1 边栏不可见（两层问题）**
- `#playerLayer`（fixed 全屏视频层）原 z-index:50，遮蔽 `#viewport`（z-index:1）内全部内容 → 降到 5
- `#pages` 原为 **static 定位**，z-index 对 static 元素无效 → 加 `position: relative` + `z-index:6`
- `.page` 背景原 `#000` 会盖住视频层 → 改 `transparent`，视频透出

**BUG-2 切回主页暂停**
- `updatePlayback` 中 `video.play()`（非静音）超出用户手势窗口被自动播放策略拒绝，promise 被 `p.catch(()=>{})` 吞掉 → catch 内 `muted=true` 静音兜底重试
- `finishSwipe` 不同步 `viewport.dataset.page` → 补 `viewport.dataset.page = currentPage`

### 修复文件
- `public/style.css`：#playerLayer z-index 50→5；.pages 加 position:relative + z-index:6；.page background 改 transparent
- `public/app.js`：updatePlayback play() 静音兜底；finishSwipe dataset 同步

  - BUG-2 切回主页 paused=False，时间轴 3.83→5.04

### 教训
- z-index 对 static 定位元素无效！flex 容器里的元素想用 z-index 必须加 position（relative/absolute/fixed）
- 浏览器自动播放策略：手势窗口结束后的 `play()`（非静音）会被拒，catch 里必须兜底（静音重试），不能吞掉 promise
