### 翻页阈值调整：方向锁定 + 速度豁免（deploy + push 完成）

1. **需求**：用户反馈「上下翻页要合理的距离，现在左右滑动不小心就翻页了，这个阈值太低了」——横向翻页阈值偏低，左右轻滑易误翻页；纵向 1/4 屏吸附距离保持合理不动。

2. **`public/app.js` 改动**（commit `0b88329`，29 insertions / 9 deletions）：
   - `SWIPE_THRESHOLD` 固定 220 → `Math.max(240, Math.round(window.innerWidth * 0.35))`（视口 1280 时 = 448，相对视口自适应）
   - 新增 `AXIS_LOCK_DIST = 18` 常量 + `axisLock` 状态变量（null | 'h' | 'v'）：touchmove/mousemove 中首次显著位移后锁定主轴，斜向/微抖不再误判横向
   - `VELOCITY_THRESHOLD` 0.3 → 0.5（px/ms）
   - `finishSwipe` 速度豁免：`|dx| >= 0.6*阈值` 且 `|dx|/dt > 0.5` 即翻页（快速轻扫仍可有意翻页）
   - `touchstart`/`mousedown` 重置 `axisLock`
   - 纵向吸附距离 `h * 0.25` 保持未变

3. **TDD 验证**：`/tmp/test_swipe_threshold.py`（8 项用例，每例前 reload 重置状态，全局参数置于文件顶部）**8 PASS / 0 FAIL**：
   - T1 斜向慢滑(350,150)、T2 横向慢滑(-350) 均 < 448 → 不翻页（旧代码 220 阈值下两例失败，即用户反馈的误触）
   - T3 纵向小幅 dy=+150 < 180 → 吸附回弹 scrollTop=3h
   - T4 方向锁定（先 dy=100 再 dx=350）→ 不翻页、回弹
   - T5 大幅左滑 -500 > 448 → 设置页；T6 先左滑到设置页再大幅右滑 → 回主页
   - T7 纵向大幅上滑 -300 → 切下一视频；T8 快速轻扫 -300 → 速度豁免翻页
   - 修正：T6 原用例逻辑错误（reload 后从主页右滑会去 info 页），改为前置左滑到设置页再验证右滑回主页
